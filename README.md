# All File Reader

All File Reader is an Android document-reader project under development.

## Technology

- Kotlin
- Jetpack Compose
- Material 3

## Current status

Initial project setup.

## Open and run

1. Open Android Studio and select **Open**.
2. Choose this project's root directory.
3. Allow Android Studio to sync the Gradle project and install any requested SDK components.
4. Select an Android emulator or connected device.
5. Click **Run** to build and launch the app.
